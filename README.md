# 🛡️ App Pulseras DOOR
Aplicación oficial para la lectura y escritura de pulseras de seguridad NFC.

### 🚀 Instalación:
1. Descarga el archivo **App.Door.V2.apk** desde este repositorio.
2. Abre el archivo en tu dispositivo Android.
3. Si el sistema lo solicita, permite la "Instalación desde fuentes desconocidas".
4. ¡Configura tus datos de emergencia y mantente protegido!
